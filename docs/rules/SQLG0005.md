# SQLG0005 — LIKE with leading wildcard

| Field | Value |
|-------|-------|
| Rule ID | SQLG0005 |
| Title | LIKE with leading wildcard |
| Category | Performance |
| Severity | Medium |
| Auto-fix | Not supported |
| Tags | like, sargable, index |
| Database compatibility | SQL Server, Azure SQL |

## Problem

A `LIKE` pattern that begins with `%` or `_` typically prevents an index seek on that column (non-sargable predicate).

## Detection

Find `LikePredicate` nodes whose pattern is a string literal starting with `%` or `_`.

## False positives

- Patterns that must match contains-search by design (consider full-text search instead)
- Non-literal patterns (variables) are not flagged in v1

## Examples

Bad:

```sql
SELECT Id FROM dbo.Products WHERE Name LIKE '%widget%';
```

Good:

```sql
SELECT Id FROM dbo.Products WHERE Name LIKE 'widget%';
```
