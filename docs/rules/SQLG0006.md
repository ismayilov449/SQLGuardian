# SQLG0006 — CROSS JOIN

| Field | Value |
|-------|-------|
| Rule ID | SQLG0006 |
| Title | CROSS JOIN usage |
| Category | Performance |
| Severity | Medium |
| Auto-fix | Not supported |
| Tags | join, cross-join, cardinality |
| Database compatibility | SQL Server, Azure SQL |

## Problem

`CROSS JOIN` produces a Cartesian product and often indicates a missing join predicate (or an expensive intentional cross product).

## Detection

Flag `UnqualifiedJoin` nodes with `UnqualifiedJoinType.CrossJoin`.

## False positives

- Intentional series/matrix generation (suppress via config)

## Examples

Bad:

```sql
SELECT * FROM dbo.Users CROSS JOIN dbo.Regions;
```

Good:

```sql
SELECT u.Id, r.Name
FROM dbo.Users AS u
INNER JOIN dbo.UserRegions AS ur ON ur.UserId = u.Id
INNER JOIN dbo.Regions AS r ON r.Id = ur.RegionId;
```
