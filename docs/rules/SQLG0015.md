# SQLG0015 — Missing SET NOCOUNT ON

| Field | Value |
|-------|-------|
| Rule ID | SQLG0015 |
| Title | Missing SET NOCOUNT ON in module |
| Category | BestPractices |
| Severity | Low |
| Auto-fix | Supported (template) |
| Tags | nocount, procedure, trigger |
| Database compatibility | SQL Server, Azure SQL |

## Problem

Procedures and triggers that omit `SET NOCOUNT ON` send row-count DONE messages to clients, adding network chatter and breaking some clients.

## Detection

Flag `CREATE`/`ALTER` PROCEDURE or TRIGGER bodies that do not contain `SET NOCOUNT ON`.

## Examples

Bad:

```sql
CREATE PROCEDURE dbo.GetUsers AS
BEGIN
  SELECT Id FROM dbo.Users;
END
```

Good:

```sql
CREATE PROCEDURE dbo.GetUsers AS
BEGIN
  SET NOCOUNT ON;
  SELECT Id FROM dbo.Users;
END
```
