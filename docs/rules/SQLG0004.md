# SQLG0004 — TOP without ORDER BY

| Field | Value |
|-------|-------|
| Rule ID | SQLG0004 |
| Title | TOP without ORDER BY |
| Category | Correctness |
| Severity | Medium |
| Auto-fix | Not supported |
| Tags | top, order-by, nondeterministic |
| Database compatibility | SQL Server, Azure SQL |

## Problem

`TOP` without `ORDER BY` makes the result set non-deterministic; which rows are returned can change with plan, indexes, or parallelism.

## Detection

Flag `QuerySpecification` nodes that have a `TopRowFilter` and a null `OrderByClause`.

## False positives

- Existence checks where any row is acceptable (e.g. `IF EXISTS` patterns — still prefer `EXISTS` over `TOP 1` without order)
- `TOP` with `ORDER BY` on a parent `BinaryQueryExpression` may require future enhancement; v1 checks the query specification itself

## Examples

Bad:

```sql
SELECT TOP 10 Id, Name FROM dbo.Users;
```

Good:

```sql
SELECT TOP 10 Id, Name FROM dbo.Users ORDER BY CreatedAt DESC;
```
