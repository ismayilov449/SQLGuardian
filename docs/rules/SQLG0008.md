# SQLG0008 — UNION instead of UNION ALL

| Field | Value |
|-------|-------|
| Rule ID | SQLG0008 |
| Title | UNION instead of UNION ALL |
| Category | Performance |
| Severity | Low |
| Auto-fix | Not supported |
| Tags | union, distinct, sort |
| Database compatibility | SQL Server, Azure SQL |

## Problem

`UNION` removes duplicates (typically via sort/hash), which is more expensive than `UNION ALL`. If duplicates are impossible or acceptable, `UNION ALL` is cheaper.

## Detection

Flag `BinaryQueryExpression` with `BinaryQueryExpressionType.Union` and `All == false`.

## False positives

- Cases where duplicate elimination is required — keep `UNION` and suppress the finding

## Examples

Bad (when duplicates cannot occur):

```sql
SELECT Id FROM dbo.A
UNION
SELECT Id FROM dbo.B;
```

Good:

```sql
SELECT Id FROM dbo.A
UNION ALL
SELECT Id FROM dbo.B;
```
