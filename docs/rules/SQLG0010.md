# SQLG0010 — WAITFOR DELAY

| Field | Value |
|-------|-------|
| Rule ID | SQLG0010 |
| Title | Avoid WAITFOR DELAY |
| Category | BestPractices |
| Severity | High |
| Auto-fix | Not supported |
| Tags | waitfor, delay, blocking |
| Database compatibility | SQL Server, Azure SQL |

## Problem

`WAITFOR DELAY` blocks a worker for a fixed time. In application or procedure code it often indicates timing hacks, polling, or accidental performance sinks.

## Detection

Flag `WaitForStatement` nodes with `WaitForOption.Delay`.

## False positives

- Controlled demo/training scripts (suppress via config)

## Examples

Bad:

```sql
WAITFOR DELAY '00:00:05';
```

Good:

```sql
-- Use async app logic, Service Broker, or event-driven waits instead of sleeping in T-SQL
```

Implicit conversion detection requires schema metadata and is deferred; `WAITFOR DELAY` is the Task 3 stand-in for SQLG0010.
