# SQLG0022 — Non-leading index key filter

| Field | Value |
|-------|-------|
| Rule ID | SQLG0022 |
| Title | Filter on non-leading index key |
| Category | Indexing |
| Severity | Low |
| Auto-fix | Conditional (CREATE INDEX suggestion) |
| Tags | schema, index, leading-key |
| Database compatibility | SQL Server, Azure SQL |

## Problem

Filtering/joining on a column that appears only as a **non-leading** index key usually cannot seek that index efficiently. Prefer a dedicated leading-key index (see also SQLG0012).

## Detection

Requires schema. For equality predicates on a column: if the table is large enough, an index contains the column but **no** index leads with it, flag the column.

## Examples

Index `(A, B)` — filter on `B` alone is non-leading.
