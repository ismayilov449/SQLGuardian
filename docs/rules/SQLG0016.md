# SQLG0016 — NOT IN subquery

| Field | Value |
|-------|-------|
| Rule ID | SQLG0016 |
| Title | Prefer NOT EXISTS over NOT IN (subquery) |
| Category | Correctness |
| Severity | Medium |
| Auto-fix | Not supported |
| Tags | not-in, exists, null |
| Database compatibility | SQL Server, Azure SQL |

## Problem

`NOT IN (subquery)` returns no rows if the subquery produces any `NULL`. `NOT EXISTS` has clearer three-valued-logic behavior and often better plans.

## Detection

Flag `InPredicate` with `NOT` and a subquery.

## Examples

Bad:

```sql
SELECT Id FROM dbo.Users WHERE Id NOT IN (SELECT UserId FROM dbo.Orders);
```

Good:

```sql
SELECT u.Id FROM dbo.Users u
WHERE NOT EXISTS (SELECT 1 FROM dbo.Orders o WHERE o.UserId = u.Id);
```
