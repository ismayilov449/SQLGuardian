# SQLG0001 — Avoid SELECT *

| Field | Value |
|-------|-------|
| Rule ID | SQLG0001 |
| Title | Avoid SELECT * |
| Category | Performance |
| Severity | Medium |
| Auto-fix | Conditional (when schema metadata is available) |
| Tags | select, wildcard, io |
| Database compatibility | SQL Server, Azure SQL |

## Problem

Selecting all columns increases I/O, memory usage, and network traffic, and couples queries to table shape changes.

## Detection

Detect `SelectStarExpression` nodes in the ScriptDom AST (SELECT-list wildcards). Do not use regex.

## False positives

- Ad-hoc exploration queries (optional suppression via config)
- `COUNT(*)` and other aggregate stars — these are not `SelectStarExpression` and must not be flagged

## Auto-fix

Replace wildcard with an explicit column list when schema metadata is available.

## Examples

Bad:

```sql
SELECT * FROM dbo.Users;
```

Good:

```sql
SELECT Id, Name, Email FROM dbo.Users;
```
