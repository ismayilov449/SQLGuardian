# SQLG0020 — OPENROWSET / OPENDATASOURCE

| Field | Value |
|-------|-------|
| Rule ID | SQLG0020 |
| Title | Avoid OPENROWSET / OPENDATASOURCE |
| Category | Security |
| Severity | High |
| Auto-fix | Not supported |
| Tags | openrowset, opendatasource, security |
| Database compatibility | SQL Server |

## Problem

Ad-hoc distributed queries bypass controlled linked-server patterns and expand the attack surface.

## Detection

Flag `OPENROWSET` / `OPENDATASOURCE` table references and function-style usage.

## Examples

Bad:

```sql
SELECT * FROM OPENROWSET('SQLNCLI', '…', 'SELECT 1');
```
