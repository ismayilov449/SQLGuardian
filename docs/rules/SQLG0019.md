# SQLG0019 — xp_cmdshell usage

| Field | Value |
|-------|-------|
| Rule ID | SQLG0019 |
| Title | Avoid xp_cmdshell |
| Category | Security |
| Severity | Critical |
| Auto-fix | Not supported |
| Tags | xp_cmdshell, security, surface |
| Database compatibility | SQL Server |

## Problem

`xp_cmdshell` runs OS commands under the SQL Server service account and is a high-risk surface area.

## Detection

Flag references to `xp_cmdshell` in `EXECUTE` / procedure calls.

## Examples

Bad:

```sql
EXEC xp_cmdshell 'dir';
```
