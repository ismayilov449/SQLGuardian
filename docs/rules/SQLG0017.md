# SQLG0017 — IN subquery prefer EXISTS

| Field | Value |
|-------|-------|
| Rule ID | SQLG0017 |
| Title | Prefer EXISTS over IN (subquery) |
| Category | Performance |
| Severity | Low |
| Auto-fix | Not supported |
| Tags | in, exists, subquery |
| Database compatibility | SQL Server, Azure SQL |

## Problem

`col IN (SELECT …)` is often clearer and sometimes safer as `EXISTS` (semi-join), especially for existence checks.

## Detection

Flag `InPredicate` (not negated) whose right-hand side is a subquery.

## Examples

Bad:

```sql
SELECT Id FROM dbo.Users WHERE Id IN (SELECT UserId FROM dbo.Orders);
```

Good:

```sql
SELECT u.Id FROM dbo.Users u
WHERE EXISTS (SELECT 1 FROM dbo.Orders o WHERE o.UserId = u.Id);
```
