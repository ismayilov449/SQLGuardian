# SQLG0021 — TRUNCATE TABLE

| Field | Value |
|-------|-------|
| Rule ID | SQLG0021 |
| Title | TRUNCATE TABLE usage |
| Category | Correctness |
| Severity | High |
| Auto-fix | Not supported |
| Tags | truncate, ddl, destructive |
| Database compatibility | SQL Server, Azure SQL |

## Problem

`TRUNCATE TABLE` is minimally logged, cannot be partially rolled back like a filtered `DELETE`, and is often accidental in scripts.

## Detection

Flag `TruncateTableStatement` nodes.

## Examples

Bad:

```sql
TRUNCATE TABLE dbo.Users;
```

Good:

```sql
DELETE FROM dbo.Users WHERE …; -- intentional, filtered
```
